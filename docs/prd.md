# 需求文档

## 1. 应用概述

### 1.1 应用名称
智学伴

### 1.2 应用描述
面向高等教育阶段（本科、研究生、高职）学生的个性化学习系统，聚焦计算机、人工智能、电子信息等专业，提供「画像构建-资源生成-路径规划-学习辅导-效果评估」全流程个性化学习服务。

## 2. 用户与使用场景

### 2.1 目标用户
高等教育阶段学生（本科、研究生、高职），专业方向为计算机、人工智能、电子信息等

### 2.2 核心使用场景
- 学生需要根据自身学习基础和目标获取个性化学习资源
- 学生需要明确的学习路径指导，避免盲目学习
- 学生在学习过程中遇到问题需要即时答疑
- 学生需要了解自身学习效果并获得改进建议

### 3.2 功能说明

#### 3.2.1 登录/注册页
- 支持手机号验证码登录
- 支持邮箱验证码登录
- 新用户注册时需填写：手机号/邮箱、验证码、密码、专业、学历

#### 3.2.2 首页总览
- 展示快捷操作组件（位于当前学习路径上方），包含：资源生成入口、智能答疑入口
- 展示当前学习路径概览
- 展示今日推荐资源（以卡片形式呈现，包含资源类型、标题、简介）
- 展示学习进度概览（已学习资源数量、完成练习数量）
- 左侧边栏导航菜单（电脑端），包含：首页、资源中心、学习路径、智能答疑、学习工具箱
- 顶部右上角区域（从左到右顺序）：智能体可视化按钮（图标）、竞争战略按钮（图标）、邀请有礼积分与套餐按钮（样式突出，渐变或高亮）、通知铃铛、个人中心按钮（用户头像+名称）、设置按钮（独立图标）

#### 3.2.3 个人中心
- 展示和编辑个人基本信息：专业、学历、学习目标
- 展示动态学习画像详情，包含至少6个维度：知识基础、认知风格、易错点偏好、学习节奏、学习目标、专业方向
- 展示学习记录：已查看的资源列表、练习完成情况
- 系统设置：界面主题切换、通知开关
- 帮助中心入口

#### 3.2.4 学习画像构建页
- 通过对话方式收集用户信息，包括：专业、学习目标、学习历史、知识基础、认知习惯、易错点等
- 用户以自然语言输入回答
- 系统根据对话内容和学习行为数据（资源查看记录、练习错题）构建包含至少6个维度的学习画像
- 画像支持动态更新，当用户学习行为发生变化时提示画像已更新
- 展示完整的画像详情
- **语音通话功能按钮**：
  + 位于「学习画像构建」标题旁的右侧
  + 界面设计模仿视频/语音通话App界面
  + 拨通前显示对方头像和数字
  + 接通后全屏显示对方画面，右上角显示自己小画面
  + 底部包含功能按钮：静音、挂断、关扬声器、摄像头、切换语音等
  + 界面美观，交互效果流畅
  + 旁边构建进度和下面小提示组件保持不变

#### 3.2.5 资源中心

**资源列表**
- 展示已生成的学习资源，包含7类：教学案例、知识点思维导图、练习题库、动画演示、课件PPT、代码实操案例、学习视频
- 资源以分类结构化方式展示，内容禁止出现星号符号
- 资源卡片显示：资源类型、标题、生成时间、已读/未读状态
- 支持按资源类型筛选
- 支持按课程章节筛选

**资源生成页**
- 用户选择专业和课程章节
- **资源主题输入框旁新增课程下拉框**：支持选择计算机/人工智能大类下的具体课程（如数据结构、算法、机器学习等）
- 用户选择需要生成的资源类型（可多选），资源类型包含：教学案例、知识点思维导图、练习题库、动画演示、课件PPT、代码实操案例、学习视频
- 用户可输入知识短板描述（可选）
- 提交后展示资源生成进度
- 生成完成后提供资源查看和下载入口

**资源详情页**
- 在线查看资源内容（文档、思维导图、题库、视频等）
- 提供资源下载功能
- 支持用户编辑资源内容（文档、思维导图、题库可编辑）
- 保存编辑后的自定义版本
- 展示资源版本记录（原始版、修改版）

#### 3.2.6 学习路径页
- 展示分阶段的学习路径，明确每个阶段的学习步骤、顺序、目标
- 每个学习节点关联对应的推荐资源
- 标记已完成的学习节点
- 当学习进度或画像更新时，提示学习路径已动态调整
- 展示资源的已读/未读状态

#### 3.2.7 智能答疑
- 用户输入学习问题（支持文字和图片）
- **新增多样化解答形式按钮**：详细文字解答、图解说明、短视频讲解，结合多模态生成技术提供针对性学习引导
- 系统提供多形式解答：文字说明、图解、短视频
- 推荐关联知识点资源
- 记录用户的错题和疑问
- 展示历史答疑记录
- **数字人老师背景默认显示教室场景**，支持切换和自定义上传：
  + 提供多种预设背景供用户切换
  + 支持用户自定义上传背景图片

#### 3.2.8 学习效果评估页
- 展示多维度评估报告，包括：知识掌握度、学习效率、薄弱环节
- 提供学习计划调整建议
- 展示评估趋势图表（折线图或柱状图）
- 评估基于用户的学习行为数据：资源查看时长、练习正确率、错题分布、测试结果

#### 3.2.9 学习社群页
- 展示社群动态列表
- 用户可分享优质资源（以资源分享卡片形式展示）
- 用户可发布学习疑问并交流
- 用户可回复他人的疑问
- 展示热门资源推荐

#### 3.2.10 学习工具箱
- 点击侧边栏「学习工具箱」按钮，在按钮正下方inline展开二级子菜单（accordion方式）
- 包含7个工具入口：今日待办、错题本、笔记/错题本、弱项强化、知识图谱、代码实验室、学习报告
- 点击对应工具入口跳转至对应功能页面，工具箱保持展开状态，不出现折叠又展开的抖动效果

**今日待办**
- 展示今日待完成的学习任务列表
- 任务包含：待查看资源、待完成练习、待复习知识点
- 支持标记任务完成状态

**错题本**
- 展示用户练习中的错题记录
- 错题按知识点分类展示
- 支持查看错题解析和关联知识点资源

**笔记/错题本**
- 包含两个Tab：笔记、数据统计
- **笔记Tab**：
  + 展示用户在学习过程中记录的笔记列表
  + 支持新建笔记、编辑笔记、删除笔记
  + 笔记关联对应的资源或知识点
- **数据统计Tab**：
  + 展示用户错题数据统计信息
  + 展示错题分布和趋势

**弱项强化**
- 基于用户错题分布和学习画像，识别薄弱知识点
- 推荐针对性强化资源和练习
- 展示强化进度

**知识图谱**
- 以图形化方式展示课程知识点之间的关联关系
- 标记已掌握和未掌握的知识点
- 支持点击知识点查看相关资源

**代码实验室**
- 提供在线代码编辑和运行环境
- 支持多种编程语言（如Python、Java、C++）
- 展示代码运行结果
- 支持保存代码记录

**学习报告**
- 展示用户的学习数据统计：学习时长、完成资源数量、练习正确率
- 展示学习趋势图表
- 提供学习建议

#### 3.2.11 邀请有礼、积分与套餐页

**邀请好友**
- 生成用户专属邀请码和邀请链接
- 展示邀请规则：被邀请人注册成功后，邀请人获得积分奖励
- 展示已邀请人数和获得的积分总数
- 支持复制邀请码和分享邀请链接

**积分记录**
- 展示用户当前积分余额
- 展示积分获取记录：时间、来源（邀请好友、完成任务等）、获取积分数
- 展示积分消费记录：时间、用途（兑换套餐、兑换资源等）、消费积分数
- 支持按时间筛选记录

**套餐展示**
- 展示四档套餐：免费版、基础版、高级版、专业版
- 每档套餐包含：价格、功能列表、有效期
- 功能对比表格，清晰展示各档套餐的功能差异
- 支持选择套餐并跳转至支付页面
- 展示用户当前使用的套餐类型和到期时间

#### 3.2.12 智能体可视化页
- 展示智能体协作流程和状态信息
- 用户通过顶部右上角图标按钮进入

#### 3.2.13 竞争战略页
- 展示竞争战略相关内容
- 用户通过顶部右上角图标按钮进入
- **多智能体协作可视化面板融合在竞争战略界面内部**：
  + 新增「多智能体协作可视化」入口按钮
  + 点击按钮后在竞争战略界面内部展示多智能体协作可视化内容（不再是弹窗或独立区域）
  + 包含三个工作流：资源生成工作流、答疑辅导工作流、学习路径工作流
  + 每个工作流有各自独立的智能体节点状态动画
  + 协作消息日志展示在智能体节点状态组件下方
  + 界面美观，动画效果流畅

## 4. 业务规则与逻辑

### 4.1 学习画像构建规则
- 画像初始构建通过对话方式完成，至少包含6个维度
- 画像支持动态更新：当用户完成一定数量的练习（如10题以上）或查看资源达到一定时长（如累计2小时以上）时，系统自动更新画像
- 画像更新后需在首页或个人中心提示用户

### 4.2 资源生成规则
- 资源生成基于用户的学习画像、选择的专业和课程章节
- 用户可通过课程下拉框选择计算机/人工智能大类下的具体课程（如数据结构、算法、机器学习等）
- 每次生成请求必须至少生成7类资源：教学案例、知识点思维导图、练习题库、动画演示、课件PPT、代码实操案例、学习视频
- 资源生成过程展示进度提示
- 生成的资源自动关联到对应的课程章节
- 资源内容以分类结构化方式展示，禁止出现星号符号

### 4.3 学习路径规划规则
- 学习路径基于用户画像和学习进度动态生成
- 路径分为多个阶段，每个阶段包含明确的学习目标和推荐资源
- 当用户完成某阶段的学习（查看完该阶段所有推荐资源且完成相关练习）后，自动解锁下一阶段
- 当用户画像更新或学习进度发生变化时，路径可能调整，需提示用户

### 4.4 资源推送规则
- 系统根据用户当前学习节点精准推送适配资源
- 推送的资源类型需多样化，包含教学案例、思维导图、题库、动画演示、课件PPT、代码实操案例、学习视频等
- 已推送但未查看的资源标记为「未读」，查看后标记为「已读」

### 4.5 答疑规则
- 用户提问时，系统根据问题内容和用户当前学习章节提供解答
- 用户可选择解答形式：详细文字解答、图解说明、短视频讲解
- 解答形式根据问题类型自动选择：概念类问题提供文字+图解，操作类问题提供短视频
- 每次答疑后推荐3个关联知识点资源
- 用户标记为「错题」或「疑问」的内容自动记录到个人中心
- 数字人老师背景默认显示教室场景

### 4.6 学习效果评估规则
- 评估基于用户的学习行为数据：资源查看时长、练习正确率、错题分布
- 评估报告包含至少3个维度：知识掌握度（基于练习正确率）、学习效率（基于资源查看时长与完成进度比）、薄弱环节（基于错题分布）
- 评估完成后提供学习计划调整建议，如：增加某知识点的练习、调整学习节奏等

### 4.7 资源编辑规则
- 用户可编辑的资源类型：文档、思维导图、题库
- 编辑后的资源保存为新版本，原始版本保留
- 资源版本记录展示：原始版（系统生成）、修改版（用户编辑）

### 4.8 社群互动规则
- 用户可分享已生成的资源到社群
- 用户可发布学习疑问，其他用户可回复
- 社群动态按时间倒序展示
- 热门资源推荐基于资源被分享次数和查看次数

### 4.9 学习工具箱规则
- 点击侧边栏「学习工具箱」按钮，在按钮正下方inline展开二级子菜单
- 再次点击按钮或点击其他区域时，子菜单收起
- 子菜单包含7个工具入口，点击后跳转至对应功能页面，工具箱保持展开状态，不出现折叠又展开的抖动效果

### 4.10 邀请与积分规则
- 用户成功邀请好友注册后，邀请人获得积分奖励（如50积分）
- 积分可用于兑换套餐或兑换学习资源
- 积分获取来源：邀请好友、完成学习任务、参与活动等
- 积分消费用途：兑换套餐、兑换资源、参与抽奖等

### 4.11 套餐规则
- 四档套餐：免费版、基础版、高级版、专业版
- 免费版：基础功能，资源生成数量有限
- 基础版：增加资源生成数量，开放部分高级功能
- 高级版：资源生成数量更多，开放更多高级功能
- 专业版：无限资源生成，开放全部功能
- 用户购买套餐后，套餐立即生效，有效期从购买时间开始计算
- 套餐到期后，用户权限自动降级至免费版

### 4.12 语音通话规则
- 用户在学习画像构建页点击语音通话按钮后，发起语音通话请求
- 拨通前显示对方头像和数字
- 接通后全屏显示对方画面，右上角显示自己小画面
- 用户可使用底部功能按钮控制通话状态：静音、挂断、关扬声器、摄像头、切换语音等

### 4.13 答疑中心背景切换规则
- 数字人老师背景默认显示教室场景
- 用户可在智能答疑选择预设背景或上传自定义背景图片
- 背景切换后立即生效
- 自定义上传的背景图片保存至用户个人设置

### 4.14 多智能体协作可视化规则
- 用户在竞争战略页点击「多智能体协作可视化」入口按钮后，在竞争战略界面内部展示多智能体协作可视化内容
- 界面包含三个工作流：资源生成工作流、答疑辅导工作流、学习路径工作流
- 每个工作流有各自独立的智能体节点状态动画
- 协作消息日志实时更新，展示在智能体节点状态组件下方

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理方式 |
|------|----------|----------|
| 登录/注册 | 验证码错误 | 提示「验证码错误，请重新输入」 |
| 登录/注册 | 手机号/邮箱已注册 | 提示「该手机号/邮箱已注册，请直接登录」 |
| 画像构建 | 用户输入信息不完整 | 继续引导用户补充信息，直到至少6个维度完整 |

## 6. 验收标准

1. 用户完成注册并登录系统
2. 用户通过对话方式完成学习画像构建（至少6个维度），点击标题右侧语音通话按钮发起语音通话
3. 用户在资源生成页选择专业、通过课程下拉框选择具体课程（如数据结构、算法、机器学习等），生成7类学习资源（教学案例、知识点思维导图、练习题库、动画演示、课件PPT、代码实操案例、学习视频），资源以分类结构化方式展示且内容无星号符号
4. 用户查看学习路径，点击路径节点查看推荐资源
5. 用户在智能答疑提出问题，选择解答形式（详细文字解答、图解说明、短视频讲解）并获得解答，切换数字人老师背景或上传自定义背景图片
6. 用户完成练习题，查看学习效果评估报告
7. 用户点击侧边栏「学习工具箱」按钮，inline展开二级子菜单，点击「笔记/错题本」进入笔记/错题本页面，切换至「数据统计」Tab查看错题数据统计，工具箱保持展开状态无抖动
8. 用户点击顶部右上角「邀请有礼、积分与套餐」按钮，进入邀请页面，生成邀请码并复制
9. 用户查看积分记录和套餐展示页面
10. 用户点击竞争战略页「多智能体协作可视化」入口按钮，在竞争战略界面内部查看三个工作流的智能体节点状态动画和协作消息日志
