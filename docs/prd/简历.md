### 💡 模块 B：PM 核心项目功能与产品深挖（10 大功能模块视角 - STAR 原则）

#### 1. 产品定位与用户痛点摸底 (Product Strategy & User Research)
- **S/T (背景与任务)**：高等教育理工科学生普遍面临课程体系庞杂、备考缺乏重点、代码报错无人辅导等痛点；教师端面临课件备课工作量巨大、难以因材施教的困境。
- **A (关键行动)**：深入调研 Duolingo、Khan Academy 等竞品，明确平台定位为“面向高校理工科的自适应智能学习助手”；编写 30+ 页面级高保真 PRD，规划“画像诊断-路径规划-资源生成-启发答疑-效果评估”完整闭环。
- **R (效果与成果)**：确立了 7 类 AI 资源生成规范与多 Agent 协作流程，产品方案 100% 覆盖研发落地，成功构筑差异化助学产品壁垒。

#### 2. 苏格拉底多轮对话画像诊断设计 (Conversational AI Profiling & Socrates Prompt)
- **S/T (背景与任务)**：传统静态问卷无法真实捕捉学生的认知风格、实际基础储备与易错习惯，导致后续个性化推荐颗粒度粗糙。
- **A (关键行动)**：设计基于苏格拉底启发式提问的 5-6 轮多轮对话诊断流程，结合阶跃 StepAudio 实时语音交互；制定 strict JSON Schema 提示词策略，要求 AI 在对话结束时自动提炼并输出包含 6 维认知风格的评分向量。
- **R (效果与成果)**：实现了无痛、高粘性的能力摸底体验，成功将非结构化对话沉淀为结构化 `learning_portraits` 数据，为后续路径自适应调整提供了精准基座。

#### 3. 自适应学习路径与 DAG 依赖图谱规划 (Adaptive Path Planning & DAG Rules)
- **S/T (背景与任务)**：传统在线课程采用固定线性目录，无法根据学生的初始能力差异与阶段诊断结果进行动态分层和路线重排。
- **A (关键行动)**：抽象理工科课程知识点的先修依赖关系，设计基于 DAG（有向无环图）的学习路径规划算法规则；定义节点锁定/解锁机制及诊断评估后的路径自适应重排逻辑。
- **R (效果与成果)**：实现了“千人千面”的自适应学习图谱，学生在完成阶段测试后可动态调整攻坚节点，大幅降低掉队率与学习焦虑感。

#### 4. 多模型生态选型与 Prompt 架构设计 (Multi-Model Evaluation & Prompt Architecture)
- **S/T (背景与任务)**：单一模型无法兼顾响应时延、成本控制、多模态能力与代码专业度的综合需求。
- **A (关键行动)**：评估并搭建多模型路由策略：选用 DeepSeek-v4-pro 处理代码 Review 与复杂推理，MiniMax-M3 负责通用对话与资源生成（设置 `ernie-speed` 自动降级兜底）；配合阶跃 StepAudio 处理语音、可灵 Kling 渲染数字人视频；设计统一的 System Prompt 规范与 JSON Schema 校验机制。
- **R (效果与成果)**：构筑了高可用、低成本的多模型服务矩阵，将 AI 输出格式解析异常率降低至 1% 以下，显著提升多模态交互体验。

#### 5. 流式资源生成与「我的资源」一站式 CRUD 抽屉 UX (Resource Generation & CRUD Asset Drawer)
- **S/T (背景与任务)**：用户使用 AI 生成教学文档、思维导图与习题后，缺乏持久化的资产管理、检索与富文本编辑能力。
- **A (关键行动)**：设计涵盖文档、思维导图、练习题等 7 类资源的 SSE 流式生成交互大盘；创新推出侧边暗色毛玻璃“我的资源”管理抽屉，提供完整的 C（创建）、R（预览）、U（在线编辑）、D（删除/归档）生命周期管理。
- **R (效果与成果)**：单份资源生成耗时压缩至 10 秒以内，将单次 AI 对话产物转化为用户可随时重构和二次沉淀的个人教学资产。

#### 6. 数字人启发式答疑与多模态交互设计 (Digital Human Tutoring & Multimodal UX)
- **S/T (背景与任务)**：传统 AI 答疑容易直接输出标准答案导致学生产生依赖，且纯文本交互缺乏教学沉浸感。
- **A (关键行动)**：制定“启发式答疑”产品原则（肯定探索 -> 指出逻辑漏洞 -> 提出引导性提问，禁止直接输出步骤）；结合 Kling 数字人视频生成与 MiniMax-TTS 语音播报，支持学生上传代码截图与公式手稿。
- **R (效果与成果)**：增强了答疑过程的极客探索体验与沉浸感，有效提升学生独立思考时长，打造了差异化的数字人助教场景。

#### 7. 三维知识图谱与多 Agent 协作可视化 (3D Knowledge Graph & Agent Viz UX)
- **S/T (背景与任务)**：理工科课程概念抽象，学生难以直观把握课程整体拓扑；同时 AI 后端多 Task 协同过程对用户透明度不足。
- **A (关键行动)**：规划基于 Three.js 的 3D 空间拓扑图谱功能，定义节点旋转、拖拽、双击跳转学习的应用场景；设计“多智能体协作可视化面板”，将后台 Edge Functions 的工作流动态转为实时状态机消息流与动画展示。
- **R (效果与成果)**：将静态目录转化为高可交互的 3D 空间全景图，显著提升了产品科技感与用户对 AI 处理过程的信任度。

#### 8. Monaco 代码沙箱实验室产品化 (Online Code Sandbox & AI Review UX)
- **S/T (背景与任务)**：计算机与电子信息专业学生搭建本地开发环境门槛高，遇到代码编译报错时排查困难。
- **A (关键行动)**：规划“代码沙箱实验室”功能，集成 Monaco Editor 与 Web Worker 浏览器内运行环境（支持 8 种主流语言）；设计 DeepSeek-v4-pro 内嵌式（inline）代码审查气泡，实时展示时空复杂度分析与修改建议。
- **R (效果与成果)**：实现免配置、即开即写的代码练习闭环，打通“编写-运行-AI 审查-修复”极速反馈链条。

#### 9. 游戏化留存与社群增长机制设计 (Gamification Growth & Community Strategy)
- **S/T (背景与任务)**：自学场景下用户缺乏持续学习动力，完课率与每日活跃度（DAU）容易衰减。
- **A (关键行动)**：搭建包含每日签到打卡挂件、连续 Streak 激励、4 种稀有度成就勋章墙、全站积分/时长排行榜，以及邀请好友赠送积分的裂变机制；设计学习社区发帖与心得共享功能。
- **R (效果与成果)**：构建了完整的游戏化激励与自然裂变闭环，显著拉升了用户周复访率与社区互动频次。

#### 10. 商业化订阅套餐与微信支付闭环 (Subscription Monetization & Payment Workflow)
- **S/T (背景与任务)**：平台需要实现商业闭环，区分免费与付费权益（如高级 AI 模型调用额度、数字人视频生成频次）。
- **A (关键行动)**：规划免费版、Pro 尊享版、VIP 旗舰版等多级订阅方案；设计从套餐选择、微信扫码支付、订单状态跟踪到权益自动到账的完整产品流程。
- **R (效果与成果)**：实现了平台商业化能力从 0 到 1 的搭建，定义了清晰的 API 额度与权益控制规则。

#### 1. 现代化前端架构搭建与高性能构建 (React 18 + Vite Rolldown + Zustand + TypeScript)
- **S/T (背景与任务)**：系统包含 29 个业务子页面、高频 AI 流式渲染与复杂 3D 交互，需要具备极致的加载性能、强类型约束与易维护的全局状态。
- **A (关键行动)**：基于 React 18 + TypeScript 5 + Vite（Rolldown 引擎）搭建单页应用；采用 Zustand 结合 `persist` 中间件实现本地状态持久化；对 25 条路由配置 `React.lazy` 按需代码拆分；配合 Biome 实施严格的代码 Lint 与格式化。
- **R (效果与成果)**：实现了毫秒级 HMR 热更新，首屏加载时间大幅缩短，支撑 21,720 行纯净代码的高效维护与零类型隐患运行。

#### 2. 多 AI 模型服务层与 SSE 流式解析封装 (Multi-LLM Integration & Resilient SSE Parser)
- **S/T (背景与任务)**：需对接 DeepSeek-v4-pro、MiniMax-M3 等多个大模型，解决打字机流式输出、实时请求中断与模型故障降级问题。
- **A (关键行动)**：封装统一的 AI 服务层（`src/services/ai/deepseek.ts`），基于 `eventsource-parser` 解析 SSE 数据帧（`data: {...}`），实现 `streamChat` 与 `chat` 接口；接入 `AbortSignal` 支持用户主动终止打字；实现 MiniMax 主模型失败自动切换至 `ernie-speed` 的降级策略。
- **R (效果与成果)**：实现了首 Token 延迟 < 200ms 的极速流式对话，打字机渲染流畅无卡顿，AI 接口服务可用性达到 99.9%。

#### 3. Supabase BaaS 基础设施与 13 个 Edge Functions 研发 (Supabase Serverless & Edge Architecture)
- **S/T (背景与任务)**：避免维护重型物理服务器，同时安全托管 API 密钥、微信支付回调、网页抓取与第三方 AI 代理。
- **A (关键行动)**：使用 Deno TypeScript 编写并部署 13 个 Supabase Edge Functions（包括 `ai-chat`、`ai-generate`、`ai-evaluate`、`kling-video-create/query`、`minimax-tts`、`web-reader`、`create-payment-order`、`wechat-payment-webhook` 等），实现统一 CORS 跨域处理与密钥安全防护。
- **R (效果与成果)**：构筑了无服务器云原生后端，敏感 Key 零前端暴露，平均边缘函数响应时延低至数十毫秒。

#### 4. PostgreSQL 表结构设计与 8 个版本化 Migration 控制 (Database Schema & Migration Versioning)
- **S/T (背景与任务)**：需设计支持多租户用户 Profile、画像 JSON、课程资源 CRUD、错题本、打卡流水及支付订单的稳定数据库架构。
- **A (关键行动)**：编写 8 个版本化 SQL 迁移脚本（`00001`~`00008`），设计 `user_profiles`、`learning_portraits`、`resources`、`wrong_book_entries` 等核心表；建立 `auth.users` 联级外键，编写 PostgreSQL 触发器（Trigger）实现用户注册自动初始化 Profile 记录。
- **R (效果与成果)**：保证了数据库 Schema 的严谨性与平滑演进，支持高效的复杂关联查询与一致性约束。

#### 5. Supabase RLS 行级安全与 Auth 鉴权防护 (Granular RLS Policies & Route Guards)
- **S/T (背景与任务)**：防止多租户环境下的横向/纵向越权访问风险，确保用户仅能操作自身归属数据。
- **A (关键行动)**：为所有 PostgreSQL 数据表配置基于 `auth.uid()` 的细粒度 RLS（Row Level Security）策略；前端基于 React Context 封装 `AuthContext` 统一管理登录态，并开发路由守卫组件（`RouteGuard`）拦截未授权访问。
- **R (效果与成果)**：构建了从数据库底层到前端路由的双层安全防护网络，100% 杜绝越权读取与非法更新漏洞。

#### 6. Three.js 3D 力导向知识图谱渲染与交互 (Three.js 3D Graph & Spatial Raycasting)
- **S/T (背景与任务)**：需要在 Web 端高效渲染数十个课程知识点节点及其复杂依赖连线，并保证 60 FPS 顺畅交互。
- **A (关键行动)**：基于 Three.js 与 WebGL 编写 3D 力导向布局算法；渲染 3D 节点球体与空间连线；利用 Raycaster 实现鼠标 Hover 高亮、旋转拖拽（OrbitControls）以及双击节点触发路由跳转事件。
- **R (效果与成果)**：实现了高性能的 3D 空间拓扑图谱渲染，画面帧率稳定在 60 FPS，交互体验极为流畅。

#### 7. Monaco Editor 代码编辑器与 Web Worker 沙箱编译 (Monaco Editor & Web Worker Execution)
- **S/T (背景与任务)**：在前端安全、无阻塞地运行多语言代码，并展示 AI 行内改错提示。
- **A (关键行动)**：集成 Monaco Editor 实现代码高亮与自动补全；利用 Web Worker 隔离构建浏览器端安全沙箱，支持 8 种语言的即时编译与日志输出；解析 DeepSeek 返回的代码位置 JSON，使用 Monaco Decorators 渲染 inline 改错气泡。
- **R (效果与成果)**：实现了零服务端编译开销的前端沙箱环境，代码审查建议行级精准对齐，用户体验顺滑。

#### 8. 高保真组件库二次封装与 CSS 硬件加速动效 (Radix UI + Tailwind + Framer Motion)
- **S/T (背景与任务)**：打造符合现代审美的高保真暗色玻璃拟态 UI，并确保复杂手风琴与弹窗动画无卡顿。
- **A (关键行动)**：基于 Radix UI / Shadcn 二次封装 50+ 个无头 UI 原子组件；使用 Tailwind CSS 自定义 CSS 变量实现深浅色主题切换；编写基于原生长宽 Flex 结合 `cubic-bezier(0.16, 1, 0.3, 1)` 贝塞尔曲线的硬件加速手风琴动效；配合 Framer Motion 呈现组件淡入与缩放。
- **R (效果与成果)**：实现了零 Layout 重排抖动的高品质动画效果，完美适配桌面端与移动端弹性响应式布局。

#### 9. 微信支付 API 对接与 Webhook 签名验签 (WeChat Payment Integration & RSA Signature Verification)
- **S/T (背景与任务)**：接入微信支付扫码付，确保订单创建、回调验签与权益发行的绝对资金安全。
- **A (关键行动)**：在 Edge Function 中开发 `create-payment-order` 微信统一下单 API，生成带签名的支付二维码；编写 `wechat-payment-webhook` 处理微信异步通知，使用 RSASSA-PSS 算法校验微信回调报文签名，验签通过后以事务方式更新订单状态与 `user_profiles` 权益字段。
- **R (效果与成果)**：搭建了安全防篡改的微信支付全流程，实现了支付回调处理 0 漏单与权益自动秒级同步。

#### 10. 代码规范治理与 Client-Side 多格式文档导出 (Biome Linting & docx/pptxgenjs Generation)
- **S/T (背景与任务)**：保障 100+ 源文件协同质量，并支持将生成的内容一键导出为本地 Word 与 PPT 文件。
- **A (关键行动)**：配置 `biome.json` 实现秒级 Lint 与代码 Formatting；引入 `docx` 与 `pptxgenjs` 依赖库，编写前端解析转换器，将 AI 格式化的 Markdown/JSON 资源结构化导出为符合排版标准的 `.docx` 与 `.pptx` 矢量文件。
- **R (效果与成果)**：保障了代码库零 Lint Error/Warning 质量；支持教师一键生成并下载标准化教学课件，提升实用价值。
