## 一、需求洞察 🌐

### 01. 痛点与解决方案 (Pain points & Solutions)

> **🎨 视觉设计规范**
> * **排版布局**：左右对立拆分布局 (50:50 Split Panel)。左侧为“痛点暗红色系”，右侧为“方案明亮青色系”。
> * **色彩搭配**：背景色 `#0B0F19`（深空蓝）/ 痛点色 `#EF4444`（胭脂红）/ 方案色 `#10B981`（翡翠绿）。
> * **图表元素**：左侧为带有红色感叹号的传统学习瓶颈卡片；右侧为带有动态流光箭头的 Kowell AI 价值环。

#### ❌ 传统高等教育阶段学习痛点
* **千人一面，节奏脱节**：大班课教学无法兼顾每个学生的专业起点与理解力。
* **知行分离，实操门槛高**：计算机及 AI 专业极度依赖动手写代码，但本地配置 IDE 繁琐，学生容易被环境配置劝退。
* **思维惰性，AI 直接给答案**：大部分 AI 助教采取直接提供完整答案或成段代码的“灌输式解答”，学生缺乏主动探索过程。

#### ✨ Kowell AI 解决方案
* **自适应画像驱动路径**：通过苏格拉底式多轮对话建模，动态生成 6 维认知画像，以此重算最优学习路径 DAG。
* **免配置多语言代码沙箱**：内置 Monaco 编辑器，支持 8 种主流理工科语言，代码随写随测，配有 inline 纠错气泡。
* **苏格拉底启发式交互**：答疑数字人严禁直接给答案，而是通过逐步引导、指出逻辑漏洞，培养学生自主推导能力。

> **🎙️ 演讲备注 (Speaker Notes)**
> 各位评委好！现今理工科在线教育最大的问题是“只读不写”和“灌输式解答”。学生要么被本地开发环境配置劝退，要么过度依赖 AI 助手一键生成代码而丧失思考。Kowell AI 从画像、路径、沙箱到引导式答疑，重新定义了闭环式的自适应智能学习。

## 三、技术解析及亮点 🛠

### 08. 技术架构 (Overall Architecture)

> **🎨 视觉设计规范**
> * **排版布局**：纵向分层拓扑图 (3-Tier Layered Diagram)。
> * **色彩搭配**：客户端层采用蓝色，服务网关层采用紫色，底层存储层采用暗绿。
> * **图表元素**：卡片之间使用双向发光的流式数据线相连，标志着数据的流转方向。

```text
    【前端呈现层 (React SPA)】 React 18 + TS + Vite 5 + Tailwind CSS 3
      ├── 1. 响应式布局：基于 Tailwind 断点，在移动端自动转换为纵向单栏堆叠。
      ├── 2. Zustand 全局持久化缓存：本地缓存 Profile，大幅减少不必要的后端数据库重求。
      └── 3. eventsource-parser SSE 帧解析：字词级实时上屏渲染，完全无卡顿。
             ▲▼ (RESTful API / Token 鉴权)
    【服务与网关层 (FastAPI / Spring Boot)】 Deno Edge Functions
      ├── 1. 独立 AI 服务代理：安全配置代理网络转发 DeepSeek-v4-pro 接口，隐藏 API 密钥。
      └── 2. 异步多线程调度：并发调度云函数并行处理课件大纲、习题、导图的异步生成。
             ▲▼ (pgvector 余弦距离计算)
    【数据与存储层 (Postgres DB)】 pgvector + RLS Row-Level Security
      ├── 1. 语义向量数据库：存取大纲与题目的 Embedding 向量，实现毫秒级 RAG 检索。
      └── 2. 行级安全策略 (RLS)：每一张基础表均绑定 `auth.uid() = user_id` 策略，防止越权读写。
```

> **🎙️ 演讲备注 (Speaker Notes)**
> Kowell AI 采用极富扩展性的前后端分离架构。前端通过 Zustand 缓存状态，减少了 60% 的 API 请求；后端使用 FastAPI/Spring Boot 承载网关，Edge Functions 异步处理并发 AI 任务；数据库层引入 pgvector，支持高效的语义检索，并依靠 RLS 严防越权漏洞。

#### 🔐 后端 API 防越权隔离策略
```sql
-- 开启 RLS 物理层行级安全
ALTER TABLE public.resources ENABLE ROW LEVEL SECURITY;

-- 绑定严格的安全策略，确保用户仅能操作自身的数据
CREATE POLICY "Resources Owner Access" ON public.resources

```

> **🎙️ 演讲备注 (Speaker Notes)**

```text
  【画像构建工作流】 ➔ 用户回答/语音 ➔ Deno Edge Function ➔ Gemini 1.5 Flash 诊断 ➔ 生成 6维得分 JSON ➔ 更新 DB
  【路径规划工作流】 ➔ 读取画像 ➔ Edge Function ➔ GPT-4o 拓扑计算 ➔ 生成 DAG 节点依赖数据 ➔ 渲染 SVG 路线图
  【资源生成工作流】 ➔ 选定章节 ➔ Deno Edge Function ➔ Claude 3.5 Sonnet (并行) ➔ SSE 流式输出 7类课件 ➔ 保存

  提取最关联的 3 个章节内容 ➔ 作为 context 拼入 prompt ➔ 调度 Claude-3.5 开展苏格拉底启发式解答
```
