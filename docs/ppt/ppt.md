### 07. 核心及特色功能 (Core & Special Features)

> **[页面设计方案]**
> * **排版风格**：双翼对称排版 (Twin-Wing Symmetric Layout)。
> * **配色方案**：深空灰背景，霓虹蓝 (#06B6D4) 代表核心系统，烈焰粉 (#F43F5E) 代表特色创新。
> * **视觉元素**：左右两侧分栏，左侧为高内聚的核心业务，右侧为提升产品张力的爆款体验。

* **⚡ 核心系统支撑 (Core System)**
  * **🏠 首页全局大盘**：集成学习打卡历、今日推荐任务、全局学情总进度追踪。
  * **👤 个人控制中心**：动态管理专业方向、学习目标，一键刷新全局画像。
  * **🧠 苏格拉底对话画像**：多轮引导式追问，获取动态六维认知指数。
  * **🗺️ 自适应路径规划**：基于画像自动生成有向无环图 (DAG) 拓扑依赖学习路线。
  * **📖 AI 资源秒级生成**：一键并行流式输出 7 类课件、试卷、SVG 思维导图。

* **✨ 爆款特色体验 (Premium UX Highlights)**
  * **🎨 拟物手风琴折叠**：原生 CSS 变宽特效结合 GPU 加速，120fps 滑爽体验。
  * **🗂️ 我的资源 CRUD 抽屉**：高透暗色毛玻璃弹窗，支持资源预览、多版本增删改查。
  * **💻 多语言代码沙箱**：内置 Monaco 编辑器，支持 8 种语言在线运行，AI 随行改错。
  * **🕸️ 3D 空间知识图谱**：基于 Three.js 实现三维拓扑，支持漫游、缩放、双击关联。
  * **🔌 多智能体协作可视化**：将后台多 Agent 协同规划日志以流式进度条完美呈现。

* **🔐 严苛的安全隔离策略 (RLS Policies)**
  * 全库核心表均开启 Supabase 行级安全（Row Level Security），禁止外部接口直接越权访问。
  * **SQL 安全策略示例**：
    ```sql
    ALTER TABLE public.resources ENABLE ROW LEVEL SECURITY;
    
    CREATE POLICY "user_resources_isolation" 
    ON public.resources 
    FOR ALL 
    USING (auth.uid() = user_id);
    ```
  * 不管是 PC 端还是移动端发起的 API，任何用户皆无法通过越权修改获取他人的资源与错题本数据，实现了金融级的多租户物理安全。
