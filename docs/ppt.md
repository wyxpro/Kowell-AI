### 03. 项目简介 (Product Overview)

> **[页面设计方案]**
> * **排版风格**：黄金三角架构 (Pyramid Hierarchy) ── 底部双支柱，顶部大字标题。

* **📍 核心定位**：专为理工科（计算机、人工智能、电子信息）学生打造的自适应多智能体协作学习平台。
* **💡 三大核心价值**：
  1. **极速顺畅的 UX 溢价**：利用硬件加速的手风琴展示组和暗色玻璃抽屉，实现颠覆性的页面流畅度，提升产品质感。

### 10. 后端服务 (Backend & Database)

> **[页面设计方案]**
> * **排版风格**：表单关系透视 (Relational Grid Chart)。
> * **配色方案**：深邃藏青背景加上纯白字体。
> * **视觉元素**：各表关联拓扑箭头。

* **🗄️ 数据库底座设计 (Relational DB)**
  - 采用 PostgreSQL 进行核心业务托管，表结构经过三范式优化，辅以 `user_id` 触发器保障 Profile 自动创建。
  - 核心关系链：`user_profiles` ── (1对1) ── `learning_portraits` ── (1对多) ── `resources` / `wrong_book_entries`。
* **🔐 严苛的安全隔离策略 (RLS)**
  - 全表开启 Supabase 行级安全控制 (RLS)，对 Select、Insert、Update、Delete 操作进行鉴权绑定：
    `CREATE POLICY "user_data_isolation" ON public.resources FOR ALL USING (auth.uid() = user_id);`
  - 确保不论是 PC 网页端还是移动端发起的 API，任何用户绝无可能越权读写他人私有资产。

### 11. AI核心能力 (AI Orchestration & Agent Workflows)

> **[页面设计方案]**
> * **排版风格**：双段管道流程 (Pipeline Row Grid)。
> * **配色方案**：深绿 (Forest Green) 渐变至荧光绿。
> * **视觉元素**：工作流每个节点上方配有当前运转模型的圆标。

* **🧠 智能体管线编排 (Agent Pipelines)**
  1. **画像诊断 Agent** (Gemini-1.5-Flash)：以亲切导师人设，开展多轮引导追问，最终重算画像并更新 DB。
  2. **路径规划 Agent** (GPT-4o)：输入 6 维画像分值，输出严格符合依赖关系的拓扑节点 JSON 数组。
  3. **资源生成 Agent** (Claude-3.5-Sonnet)：接收请求，多线程并发，秒级并行生成大纲、题库及导图。
* **🔍 知识大纲检索增强生成 (RAG Flow)**
  - 用户提问/拍照 ➔ FastAPI/Spring Boot 提取文本 ➔ text-embedding-3 转化为向量 ➔ pgvector 余弦相似度检索 ➔ 拼接最关联的章节内容 ➔ 送入 LLM 进行启发式辅导解答。
