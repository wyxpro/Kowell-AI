### 1. Demo 简介

* **是什么**：**Kowell AI** 是一款面向高等教育阶段（本科、研究生、高职）理工科学生开发的**自适应多智能体协作智能学习与高效教研 SaaS 平台 (网站系统)**。
* **面向谁**：
  * **理工科学生**（计算机科学、人工智能、电子信息等专业）：帮助他们获得定制化的复习自测和工程实操闭环。
  * **高校教师**：帮助教师从繁重的备课任务中解放出来，实现秒级高品质教学大纲、思维导图、题库的流式生成与 CRUD 管理。
* **核心功能与界面展示**：

#### 🧠 功能一：苏格拉底 6 维画像构建与拟真语音通话
通过与 AI 导师进行 5-6 轮的启发式自然语言对话，系统动态评估并绘制出学生的六维认知画像（知识基础、认知风格、易错偏好、学习节奏、学习目标、专业方向），并支持一键发起音视频通话模式。
![6维苏格拉底AI画像对话与语音通话界面](file:///e:/Code/AI/Start/Web/Kowell%20AI/socrates_ai_avatar.png)

#### 🗺️ 功能二：DAG 拓扑自适应学习路径规划
根据六维画像的动态变动，系统自动为学生生成具有前后置节点依赖的有向无环图 (DAG) 渐进式学习路线，实时渲染各节点完成度，并结合已读/未读状态精准推送适配资源。
![DAG拓扑图自适应学习路径规划](file:///e:/Code/AI/Start/Web/Kowell%20AI/dag_learning_path.png)

#### 💻 功能三：8 语言免配置在线代码沙箱与 Inline Review
支持 C, C++, Java, Python, Go, Rust, JS, TS 8种语言在浏览器端一键编译运行，彻底抹平本地配环境的硬件鸿沟。若编译报错，AI 会即时在代码行下方生成毛玻璃改错气泡 (Inline Review) 并支持一键修改。
![8语言免配置Monaco在线编译沙箱与Inline改错气泡](file:///e:/Code/AI/Start/Web/Kowell%20AI/monaco_code_sandbox.png)

### 2. Demo 创作思路

* **灵感来源**：
  作为高校理工科专业的学生，我们在日常学习中深受“千人一面”的课本教材困扰，期末考前不知如何有针对性地攻克薄弱环节。同时，配环境、装软件（如 GCC, JDK, Python 虚拟环境）占据了大量的学习时间，经常在写出第一行 Hello World 之前就被报错劝退。此外，市面上大多的 AI 助教要么呆板问答，要么直接吐出完整答案，极易滋生学生的抄袭惰性。
* **想解决的问题（用户痛点）**：
  1. **理论与实操脱节**：学生急需一个免配置、即时运行、带 AI 诊断的编码实验室。
  2. **盲目突击效率低**：学生无法快速定位自己的核心短板，盲目刷题。
  3. **教学负担繁重**：专业课教师缺乏能够一键并行流式生成多维度配套教案（含导图、练习、PPT大纲）的辅助工具。
* **为什么做这个方向（我的判断和取舍）**：
  我们选择深耕**“高等教育理工科专业”**这一细分赛道。与 K12 教育不同，大学专业知识高度抽象且强调工程实践能力，因此仅靠简单的问答框是不够的。我们需要把大模型的流式推流能力、向量语义检索 (RAG)、WebGL 3D 拓扑图谱以及浏览器编译沙箱深度融合在一起，打造出极致滑爽（120fps 原生手风琴、暗色高透毛玻璃抽屉）的专业级系统体验。

### 4. TRAE 实践过程

使用 **TRAE**（集成智能 Agent 助手 Antigravity）极大地缩短了我们的 Demo 开发周期。以下是团队使用 TRAE 开发 Kowell AI 的完整流程：

* **开发关键步骤说明**：
  1. **第一阶段：自适应核心环境构建与启动**：我们在项目初期通过 TRAE 的 terminal 工具自动化梳理并校对了 8 个版本的 Supabase PostgreSQL 迁移脚本，一键初始化了 RLS 行级隔离策略，并排查了 Deno 云函数跨域配置。
  2. **第二阶段：极致 120fps UI 交互调优**：主页的手风琴组件起初在 Framer Motion 状态切换时有纵向抖动。我们向 TRAE 发出指令，TRAE 迅速定位并将其重构为原生 CSS flex 变换，锁定 `h-[500px]` 并开启 GPU 硬件加速，实现了 120fps 帧率级别的丝滑悬停过渡。
  3. **第三阶段：一站式资源 CRUD 玻璃抽屉开发**：我们要求 TRAE 为 `ResourceGeneratePage.tsx` 页面右侧开发一个高透毛玻璃效果的资产抽屉。TRAE 独立编写了侧边抽屉组件，与全局 Zustand Store 及 Supabase 实现了无刷新同步，支持实时预览、二次富文本修改与彻底删除。

### 🌟 5. 开发心得与 AI 协作体会

在这次 Demo 极速开发赛程中，**TRAE 表现出了颠覆传统 IDE 的全能 Agent 能力**：
1. **多文件跨目录协同理解**：当我们要求修改“我的资源抽屉”逻辑时，TRAE 能够自主定位并关联修改 `ResourceGeneratePage.tsx`、`supabase/migrations/`、`useAppStore.ts` 以及类型定义文件，完全避免了传统单卡段修改产生的类型冲突。
2. **拒绝盲目生成，主动执行与求证**：在配置运行脚本时，TRAE 没有直接丢出代码，而是主动使用命令行工具进行环境感知，检测是否存在 pnpm，并运行 `run.ps1` 校验状态，确认本地服务器 `http://localhost:5173/` 成功拉起后才交付任务，极具安全感。
